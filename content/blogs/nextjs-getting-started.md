## 什么是 Next.js？

Next.js 是一个强大的 React 框架，它提供了开箱即用的服务端渲染、静态站点生成、路由和性能优化等特性。

### 主要特点

1. **服务端渲染（SSR）**：提高首屏加载速度和 SEO
2. **静态站点生成（SSG）**：生成静态 HTML，加快页面加载
3. **自动代码分割**：按需加载 JavaScript
4. **内置 CSS 支持**：支持 CSS Modules 和 Sass

### 快速开始

```bash
npx create-next-app@latest my-next-app
cd my-next-app
npm run dev
```

开始您的 Next.js 之旅吧！
